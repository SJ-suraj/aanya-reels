Kinds: `set` (three photo urls → graded `photos/<name>/NN.jpg` + `reels/<name>.mp4`; what the routine uses; with a `"text"` object the Reel is a hook reel, see `tools/make_hook_reel.py`), `hook` (`"files"`: three already-graded repo paths + `"text"` → `reels/<name>.mp4`, no download, no grade), `reel`, `montage` (+`seconds`). Every frame is film-graded by `tools/grade_photos.py` before use. One file per job: `jobs/<name>.json` = `{"name": "<place>-<date>", "urls": ["<photo 01>", "<photo 02>", "<photo 03>"]}`; add `"kind": "montage", "seconds": 12` with any number of urls for a fast-cut montage.
Pushing it to main runs `.github/workflows/render.yml`, which writes `reels/<name>.mp4` within a couple of minutes.
