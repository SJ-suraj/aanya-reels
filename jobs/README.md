Kinds: `set` (three photo urls → graded `photos/<name>/NN.jpg` + `reels/<name>.mp4`; what the routine uses; with a `"text"` object it also builds the seven magazine pages `slides/<name>/` and the Reel is a flick through them, see `tools/make_slides.py` and `tools/make_page_reel.py`), `hook` (`"files"`: two or three already-graded repo paths + `"text"` → slides + Reel, no download, no grade), `reel`, `montage` (+`seconds`). Every frame is film-graded by `tools/grade_photos.py` before use. One file per job: `jobs/<name>.json` = `{"name": "<place>-<date>", "urls": ["<photo 01>", "<photo 02>", "<photo 03>"]}`; add `"kind": "montage", "seconds": 12` with any number of urls for a fast-cut montage.
Pushing it to main runs `.github/workflows/render.yml`, which writes `reels/<name>.mp4` within a couple of minutes.
